### 架构特点

- **纯 SPA**：无 SSR/SSG，Vite 构建后为静态资源
- **Bundler 模式 moduleResolution**：配合 `tsconfig.app.json` 中 `erasableSyntaxOnly: true`（TypeScript 6.0+ 的新严格模式）
- **路径别名**：`@` → `src/`，`@components` / `@views` / `@stores` / `@assets` 均映射到对应子目录
- **全局 CSS 变量主题**：明暗双色通过 `.dark` class 切换（配合 `@vueuse/core` 的 `useDark`）

## 四、核心架构模式

### 4.1 请求层设计 (`api.ts`)

```
apiRequest<T>(options) → fetch → 解析 → 返回 T
                  ├── 自动注入 Bearer token
                  ├── 401 检测 → refreshAccessToken() → 重试
                  │               └── 多请求排队防并发刷新
                  └── 统一错误 → ApiError { code, status, message }
```

三种请求函数：
- `apiRequest<T>` — JSON响应，自动解析 `ApiResult<T>.data`
- `apiRequestBlob` — 二进制下载，返回 `{ blob, fileName, mimeType }`
- `apiRequestStream` — 流式请求，返回原始 `Response` 对象（SSE 消费）

### 4.2 流式对话架构

```
ChatView
  ├── useAgentChat().sendMessage(message)
  │   ├── 乐观添加 user + ai 消息到 chatStore
  │   ├── fetchChatStream() → SSE Response
  │   ├── ReadableStream reader 循环
  │   │   ├── parseSSELine() → AguiEvent
  │   │   ├── RUN_STARTED → upsertStep('running')
  │   │   ├── STEP_STARTED/FINISHED → chatStore.upsertStep()
  │   │   ├── TOOL_CALL_START/RESULT → chatStore.upsertToolCall()
  │   │   └── TEXT_MESSAGE_CONTENT → pushDelta()
  │   │       └── useStreamingMarkdown.tryFlush()
  │   │           └── marked.parse() + hljs.highlight()
  │   │               └── updateAssistantMessageHtml('append')
  │   └── finally → resetMarkdown()
  └── ChatStream → UserMessageItem / AIMessageItem
```

### 4.3 状态管理模式

- **Pinia Composition Stores**：全部使用 `defineStore('name', () => { ... })`
- **模块级单例**：`useGlobalConfirmDialog` 将状态提升到模块作用域，多处引用同一实例
- **跨组件共享**：`useMessage` 同样使用模块级 `ref` 实现全局通知

### 4.4 SSE 实时推送 + 轮询降级

`useKnowledgeBaseDetail` 中的文档状态实时更新：
1. 优先 SSE 连接（带 token 预检 + 401 刷新）
2. 心跳超时 (45s) → 降级轮询 (10s 间隔)
3. 重连最多 2 次 → 再失败 → 最终降级轮询

### 4.5 主题系统

- CSS 变量驱动：`var(--color-surface)` 等 20+ 个语义变量
- 明暗切换：`.dark` class + `@vueuse/core` 的 `useDark`（响应系统偏好）
- Tailwind v4 `@theme` 块将 CSS 变量注册为 Tailwind classes
- 页面根元素 `<html class="dark">` 默认暗色
