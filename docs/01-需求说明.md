# Linsor AI 需求说明

## 产品目标

Linsor AI 是面向个人和团队的多知识库智能问答系统。系统将用户上传的文档转化为可检索知识，通过大语言模型生成带引用、可追踪的回答，并支持私有知识库、共享协作和公开访问。

## 用户与身份

- 普通用户：管理个人资料、模型配置、知识库、文档和对话。
- `owner`：知识库所有者，拥有完整管理权限。
- `manager`：管理共享库成员和全部文档。
- `collaborator`：上传文档，并管理自己上传的文档。
- `member`：浏览和问答。
- `publicVisitor`：访问公开知识库，不属于成员体系。
- 管理员：通过独立后台管理用户、管理员、模型配置、公开知识库、字典和审计日志。

## 核心功能

### 认证与账户

- 注册、登录、Token 刷新、退出和邮件验证码。
- 用户资料及密码管理。
- 系统模型和用户自定义模型配置。
- 用户模型密钥加密存储。

### 知识库

- 创建、查看、编辑和删除知识库。
- 私有、共享和公开访问。
- 邀请码加入、成员角色调整和成员移除。
- 后端执行资源级权限校验，前端按权限展示操作入口。

### 文档

- 普通上传和分片上传。
- 断点续传、重复分片幂等和基于文件哈希的秒传。
- 文档解析、结构感知分块、Embedding 和双索引写入。
- 处理进度、下载、预览、删除和版本化重解析。

### 智能问答

- 普通 Chat 与 RAG 两种模式。
- 单次对话可选择多个有权访问的知识库。
- 稠密与稀疏混合检索、融合、重排和引用。
- 查询路由、拆解、重写、检索质量判断及检索改写重试。
- AG-UI SSE 流式输出回答、步骤、工具调用和引用。
- 保存会话、消息、引用、Agent Run 和步骤追踪。

### 质量与治理

- 文档处理失败重试、任务心跳和超时扫描。
- 请求日志、统一异常、限流、健康检查和审计日志。
- RAG 回答完成后异步执行忠实度、相关性和上下文召回评估。

## 非功能要求

- 数据按用户和知识库权限隔离。
- 流式回答可取消，错误具有明确语义。
- 文档处理异步执行，不阻塞上传请求。
- 服务可通过 Docker Compose 在本地部署。
- 关键链路应具备日志、状态记录和故障降级能力。

## 范围边界

- 当前文件存储以本地存储为主，不承诺对象存储和 CDN 能力。
- 前端权限展示不是安全边界，最终权限由后端判定。
- 外部模型、搜索和邮件服务不可用时，系统应返回可理解错误或使用已定义的降级策略。
