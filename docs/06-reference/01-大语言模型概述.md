# 大语言模型（LLM）概述

## 一、LLM的定义与发展历程

大语言模型（Large Language Model，简称LLM）是一类基于深度学习技术训练的大规模神经网络模型，专门用于理解和生成自然语言文本。其核心架构是Transformer，由Google团队于2017年在论文《Attention Is All You Need》中首次提出。

### 1.1 关键里程碑

| 时间 | 事件 | 意义 |
|------|------|------|
| 2017年 | Transformer架构提出 | 奠定了LLM的技术基础 |
| 2018年 | GPT-1（1.17亿参数） | 证明了单向Transformer在文本生成上的能力 |
| 2018年 | BERT（3.4亿参数） | 引入了双向上下文理解，革新了NLU任务 |
| 2020年 | GPT-3（1750亿参数） | 展示了大模型的涌现能力（In-Context Learning） |
| 2022年 | ChatGPT发布 | 引入RLHF对齐技术，使LLM走向大众 |
| 2023年 | GPT-4 / Llama 2 | 多模态能力 + 开源生态爆发 |
| 2024年 | Claude 3.5 / GPT-4o | 推理能力显著增强，支持工具调用 |
| 2025年 | DeepSeek-R1 / Claude 4 | 推理链（Chain-of-Thought）内化为模型原生能力 |

### 1.2 参数规模演进

LLM的参数规模从最初的亿级增长到万亿级。GPT-1仅有1.17亿参数，GPT-2增加到15亿，GPT-3跃升至1750亿。PaLM达到了5400亿参数。参数量的增长带来了显著的性能提升，但同时也对计算资源提出了极高要求。值得注意的是，2024年起业界开始关注"小模型的逆袭"——通过高质量数据和精细训练，70亿参数的模型（如Mistral-7B、Qwen2.5-7B）在多项基准测试中超越了更大的模型。DeepSeek-V3采用了671B参数的MoE（Mixture of Experts）架构，每次推理仅激活约37B参数，大幅降低了推理成本。2025年发布的DeepSeek-R1更是将强化学习驱动的推理能力推向了新高度，在数学和编程等复杂推理任务上达到了与专有模型相当的水平。

## 二、Transformer架构核心

### 2.1 自注意力机制（Self-Attention）

自注意力机制是Transformer的核心创新。其计算公式为：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) * V
```

其中Q、K、V分别代表查询矩阵（Query）、键矩阵（Key）和值矩阵（Value），d_k是键向量的维度。除以√d_k的目的是防止点积结果过大导致softmax梯度消失。自注意力机制使模型能够同时关注输入序列中不同位置的信息，捕捉长距离依赖关系。其计算复杂度为O(n²)，其中n为序列长度，这是长文本处理的瓶颈。

### 2.2 多头注意力（Multi-Head Attention）

多头注意力机制将自注意力并行执行多次（通常为8-32个头），每个头在不同的表示子空间中学习不同类型的依赖关系。例如，某些注意力头可能关注语法结构，而另一些则关注语义关系。在GPT-3中，使用了96个注意力头。多头注意力的输出通过线性变换融合后传入前馈网络。

### 2.3 位置编码（Positional Encoding）与旋转位置编码（RoPE）

由于自注意力机制本身不具备顺序感知能力，需要通过位置编码注入位置信息。原始Transformer使用正弦位置编码。2023年后，旋转位置编码（Rotary Position Embedding，RoPE）成为主流方案。RoPE通过旋转矩阵对查询和键向量进行编码，使得注意力分数仅依赖于相对位置，而非绝对位置。Llama系列、Qwen系列均采用RoPE。RoPE的优势在于：支持更长的上下文长度（通过位置插值可扩展至128K乃至1M tokens），且无需额外训练即可适应推理时的长度变化。

### 2.4 前馈神经网络与残差连接

每个Transformer层包含一个前馈神经网络（FFN），通常由两个线性变换和一个激活函数（如GELU或SwiGLU）组成。残差连接和层归一化（Layer Normalization）确保深层网络的稳定训练。现代LLM中，SwiGLU激活函数因更好的梯度特性逐渐取代了传统的ReLU/GELU。SwiGLU的门控机制允许模型学习哪些信息应该通过，哪些应该被过滤。

## 三、训练范式

### 3.1 预训练（Pre-training）

预训练阶段使用海量文本语料（通常数万亿token）进行自监督学习。常用的训练目标是下一词预测（Next Token Prediction）和掩码语言建模（Masked Language Modeling）。GPT系列使用自回归（Autoregressive）方式，从左到右逐词预测。BERT使用自编码（Autoencoding）方式，随机掩码部分词语并预测。自回归模型擅长文本生成，自编码模型擅长文本理解。现代LLM如GPT-4、Llama 3的预训练数据量已超过15万亿token。数据质量被认为比数据量更重要——Llama 3的训练数据经过了严格的去重和过滤，仅保留了不到原始数据的20%。

### 3.2 有监督微调（Supervised Fine-Tuning，SFT）

在预训练基座模型的基础上，使用高质量的人工标注指令数据对模型进行微调。SFT使模型学会遵循人类指令的格式和风格，是让"基础模型"变成"助手模型"的关键步骤。通常需要1万到10万条高质量指令数据。数据多样性对模型泛化能力至关重要。

### 3.3 人类反馈强化学习（RLHF）

RLHF包含三个步骤：首先收集人类对模型回复的偏好数据（A/B比较），然后训练一个奖励模型（Reward Model）来预测人类偏好，最后使用PPO（Proximal Policy Optimization）算法优化LLM。RLHF显著提升了模型回答的有用性（Helpfulness）和安全性（Harmlessness）。2024年，DPO（Direct Preference Optimization）作为一种更简单的替代方案逐渐流行——它直接使用偏好数据优化策略模型，省去了单独的奖励模型训练步骤，降低了训练复杂度和成本。

## 四、关键能力与局限性

### 4.1 涌现能力

当模型参数超过一定阈值（通常约100亿参数），会涌现出预训练时未明确训练的新能力，包括：
- **In-Context Learning**：通过少量示例即可适应新任务，无需微调
- **Chain-of-Thought（CoT）推理**：通过逐步推理解决复杂问题
- **指令遵循**：理解并执行自然语言指令
- **多语言能力**：在未专门训练的语言上展现出翻译和理解能力

### 4.2 幻觉问题（Hallucination）

LLM最显著的局限性是"幻觉"——生成听起来合理但与事实不符的内容。幻觉产生的原因包括训练数据中的错误信息、解码策略的随机性，以及模型缺乏实时知识和外部验证机制。解决幻觉问题的主要思路包括：RAG（检索增强生成）技术、事实核查模块、输出置信度评估，以及约束解码策略。降低temperature参数可以减少输出随机性但也会降低创造性。

### 4.3 上下文窗口限制

虽然长上下文模型（如Claude 200K、GPT-4 Turbo 128K、Gemini 1M+）已大幅扩展了上下文窗口，但"Lost in the Middle"现象表明：模型对长文本中间部分的信息关注度显著下降。研究表明，模型对文档开头和结尾的内容记忆最优，中间部分的信息提取准确率下降约20-30%。因此，在RAG应用中，检索到的文档片段应尽量放置在提示词的较前位置，关键信息不要埋藏在上下文中间。

### 4.4 知识截止与时效性

LLM的知识截止于训练数据收集的日期。对于训练后发生的事件，模型无法提供准确信息。阿里云百炼平台的ChatModel支持通过`enableWebSearch`参数开启模型原生联网搜索来补充最新信息；但RAG仍是实现可控知识更新的主流方案——用户可以精确控制知识来源，且不依赖搜索引擎的质量和覆盖范围。

## 五、主流LLM家族

### 5.1 OpenAI GPT系列
GPT（Generative Pre-trained Transformer）系列由OpenAI开发。GPT-3.5作为ChatGPT的首发模型，以1.3B（Turbo版为20B）参数规模实现了流畅对话。GPT-4引入了多模态能力（文本+图像输入），在多项基准测试中达到人类水平。GPT-4 Turbo支持128K上下文长度。GPT-4o（omni）于2024年发布，统一了文本、视觉和语音处理，步入了全模态时代。o1系列（2024年末）加入了深度推理能力，通过内部思维链在答案生成前进行多步推理。

### 5.2 Anthropic Claude系列
Claude以安全性著称。Claude 2（2023年）支持100K上下文，Claude 3系列（2024年）分为Haiku、Sonnet、Opus三个版本，根据推理深度和速度分层。Claude 3.5 Sonnet在代码生成和复杂推理方面表现出色。Claude 4系列（2025年）包括Opus 4.7、Sonnet 4.6和Haiku 4.5，引入了扩展思考（Extended Thinking）和函数调用等企业级功能。

### 5.3 中国开源/商业LLM生态
- **通义千问（Qwen）系列**：阿里云开发，Qwen2.5和Qwen3系列覆盖0.5B到671B参数。Qwen3-Plus（约170B MoE，激活约30B）在学术基准和Agent任务中表现优异，是当前RAG和Agent应用的主流选择。1M Token的上下文窗口使其能处理大型文档。
- **DeepSeek系列**：DeepSeek-V3（671B MoE模型）通过创新的多头潜在注意力（MLA）机制和多token预测训练目标，以极低的训练成本达到领先水平。DeepSeek-R1在此基础上引入了强化学习驱动的长推理链，在数学竞赛和复杂的编程任务上表现出色。
- **百川（Baichuan）/ 智谱（ChatGLM）/ kimi（Moonshot）等**：形成了丰富的国产LLM矩阵，各自在不同领域有所专长。

### 5.4 选型建议
- 简单任务（路由、改写、分类）：使用qwen-turbo等轻量模型，降低延迟和成本
- 通用问答（RAG生成、总结）：使用qwen-plus或qwen3-plus，平衡质量和效率
- 复杂推理（代码生成、数学推理）：使用qwen-max或deepseek-r1，追求最高质量
- 多模态任务：使用GPT-4o或Qwen-VL系列
