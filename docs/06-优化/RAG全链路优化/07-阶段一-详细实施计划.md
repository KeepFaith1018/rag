## 1.4 Context 截断保护 [P0]

**文件**: `apps/server/src/modules/chat/services/multi-agent-orchestrator.service.ts`

**函数**: `buildContextText()` (L293-316)

**问题**: 展开到 Level 1 root chunk 后每个 ~1200 tokens，10 条 + 5 条 web results 可超 15000 tokens。

**改为**:
```typescript
function buildContextText(
  hits: RerankedHit[],
  webResults: WebSearchResult[],
  tokenService?: TokenService,  // 可选：用于精确 token 估算
): string {
  const MAX_CONTEXT_CHARS = 12000; // 约 3000 tokens，为 system prompt + answer 留空间
  const parts: string[] = [];
  let charBudget = MAX_CONTEXT_CHARS;

  if (hits.length > 0) {
    parts.push('【知识库检索结果】');
    for (let i = 0; i < hits.length; i++) {
      if (charBudget <= 0) break;
      const hit = hits[i];
      const docTitle = (hit.payload['title'] as string) || hit.title || `文档 ${hit.docId}`;
      const header = `[KB-${i + 1}] 文档: ${docTitle}\n`;
      const maxContentLen = charBudget - header.length;
      const content = hit.content.length > maxContentLen
        ? hit.content.slice(0, maxContentLen) + '...[截断]'
        : hit.content;
      parts.push(header + content);
      charBudget -= header.length + content.length;
    }
    parts.push('');
  }

  if (webResults.length > 0 && charBudget > 500) {
    parts.push('【联网搜索结果】');
    for (let i = 0; i < webResults.length; i++) {
      if (charBudget <= 0) break;
      const r = webResults[i];
      const header = `[Web-${i + 1}] ${r.title}\nURL: ${r.url}\n`;
      const maxContentLen = charBudget - header.length;
      const content = r.content.length > maxContentLen
        ? r.content.slice(0, maxContentLen) + '...[截断]'
        : r.content;
      parts.push(header + content);
      charBudget -= header.length + content.length;
    }
    parts.push('');
  }

  if (parts.length === 1) return '（未检索到相关上下文）';
  return parts.join('\n---\n');
}
```

**调用处变更** (L502-503):
```typescript
// 原来：const context = buildContextText(s.rerankedHits, s.webSearchResults);
// 改为（TokenService 可选注入）：
const context = buildContextText(s.rerankedHits, s.webSearchResults);
```

> 备选方案：如果已注入 TokenService，可用 `tokenService.tokenCount()` 做精确 token 估算。当前用字符估算（4 chars ≈ 1 token）已足够。

**验证**: 单元测试确认超长 context 被截断 + `nest build`

## 1.5 AbortSignal 完善 [P0]

### A. orchestrator — 将 signal 传入 LLM 子调用

**文件**: `apps/server/src/modules/chat/services/multi-agent-orchestrator.service.ts`

**当前状态**: `checkAborted()` 仅在节点入口检查，已发起的 LLM 调用无法中断。

**方案**: 
- route/rewrite/decompose/audit 节点的 `chatModelService.createModel()` 调用前注入 AbortSignal
- ChatOpenAI 支持通过 `timeout` 和底层 fetch 的 signal 控制

由于 LangChain ChatOpenAI 不直接支持 AbortSignal 参数，采用以下策略：
1. 在每个 LLM 调用的 `createModel` 中缩短 `timeout`（如 node 的 timeout 匹配 AbortSignal 剩余时间或固定 15s）
2. 对于 streaming writer 节点，在 `for await (const chunk of lcStream)` 循环中检查 abort（已实现 L519）

**改动** — 在 `checkAborted()` 调用处增加注释标记：
```typescript
// 各节点函数签名无需改变，LLM 调用自带 timeout 保护（15s/10s）
// 客户端断开 → checkAborted() 阻止后续节点 → 当前节点自然超时结束（最多 15s 浪费）
// 长期优化：LangGraph 的 checkpointer + interrupt() 可实现硬中断
```

> 结论：当前架构下（每个 LLM 调用 <=15s timeout），入口 checkAborted() + timeout 已提供足够保护。真正的硬中断需要 LangGraph Checkpointing（第四阶段）。

## 1.6 AgentTraceService completeRun/failRun 调用 [P1]

**问题**: `completeRun()` 和 `failRun()` 已定义但从未调用，所有 agent run 记录永远停留在 `status: 'running'`。

### 改动 A: RUN_FINISHED 后调用 completeRun

### 改动 B: catch 块中调用 failRun

在 L600-607 的 catch 块中添加:
```typescript
} catch (error: unknown) {
  const errMsg = error instanceof Error ? error.message : String(error);
  self.logger.error(`[Orchestrator] 流式编排失败: ${errMsg}`);
  writer.write({ type: 'RUN_ERROR', runId, error: errMsg });
  await self.agentTraceService.failRun(runId)
    .catch((err) => self.logger.warn('[Orchestrator] failRun 失败', { error: err }));
```

### 改动 C: 修复 SSE 事件序列

**问题**: 如果 `onFinish` 抛出异常，catch 块会发射 `RUN_ERROR`，但 `RUN_FINISHED` 可能已发射。

**方案**: 将 onFinish 包裹在 try-catch 中:
```typescript
if (onFinish) {
  try {
    const state = finalState as unknown as AgentState;
    await onFinish({
      content: state.draftAnswer ?? '',
      citations: state.rerankedHits?.slice(0, 5) ?? [],
    });
  } catch (finishError) {
    self.logger.error('[Orchestrator] onFinish 回调失败', {
      error: finishError instanceof Error ? finishError.message : String(finishError),
    });
    // 不发射 RUN_ERROR — RUN_FINISHED 已发出，SSE 流即将关闭
  }
}
```

### 改动 D: 记录 startedAt

在 L380 附近，`const runId = await self.agentTraceService.createRun(runCtx);` 之后添加:
```typescript
const startedAt = Date.now();
```

## 1.7 onFinish 回调并行化 [P1]

**文件**: `apps/server/src/modules/chat/services/chat-stream.service.ts`

**当前代码** (L119-135):
```typescript
onFinish: async (result) => {
  if (result.citations && result.citations.length > 0) {
    await this.citationService.createCitations({...});  // DB write
  }
  await this.chatMessageService.finalizeAssistantMessage(...);  // DB write
  await this.chatSessionService.summarizeTitleIfNeeded(...);    // DB + possibly LLM
},
```

**改为**:
```typescript
onFinish: async (result) => {
  const tasks: Promise<unknown>[] = [];

  if (result.citations && result.citations.length > 0) {
    tasks.push(this.citationService.createCitations({
      messageId: assistantMessage.id,
      hits: result.citations,
    }));
  }

  tasks.push(this.chatMessageService.finalizeAssistantMessage(
    assistantMessage.id,
    { content: result.content, finishReason: 'stop' },
  ));

  // summarizeTitleIfNeeded 可能调用 LLM，独立执行避免阻塞
  tasks.push(
    this.chatSessionService.summarizeTitleIfNeeded(
      dto.sessionId,
      dto.message,
      result.content,
    ).catch((err) => {
      // 摘要失败不影响主流程
      this.logger?.warn?.('会话标题生成失败', { sessionId: dto.sessionId });
    }),
  );

  await Promise.all(tasks);
},
```

> 注意：如果 `summarizeTitleIfNeeded` 内部使用了 LLM 调用且可能较慢（>2s），可以考虑不 await 它（fire-and-forget），因为 title 不是关键路径。

**验证**: `nest build` + 确认 onFinish 中三个操作无异常
