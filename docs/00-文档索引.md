# Linsor AI 文档索引

本目录只保存描述当前系统的长期文档。开发计划、实施步骤、阶段总结和临时分析默认放入 `.ai-workspace/`，不进入 Git。

## 推荐阅读顺序

1. [需求说明](01-需求说明.md)：了解产品目标、角色和功能边界。
2. [系统架构](02-系统架构.md)：了解前后端、存储、队列和数据流。
3. [数据库设计](03-数据库设计.md)：了解核心数据域及关系。
4. [后端工程规范](04-后端工程规范.md)：了解 API、异常、鉴权和日志约定。
5. [RAG 检索设计](05-RAG检索设计.md)：了解混合检索与重排。
6. [文档处理设计](06-文档处理设计.md)：了解解析、分块、向量化和索引。
7. [对话与智能体设计](07-对话与智能体设计.md)：了解 Chat、LangGraph 和 AG-UI。
8. [分片上传设计](08-分片上传设计.md)：了解断点续传、秒传和幂等。
9. [设计系统](09-设计系统.md)：了解前端视觉与交互规范。

## 文档维护约定

- 文件和子目录必须使用两位数字排序前缀，例如 `05-RAG检索设计.md`、`10-部署/`。
- 每份 Markdown 必须包含 YAML Front Matter 元数据。
- 文档只描述当前事实、稳定规则和关键设计决策，不记录逐步骤实施过程。
- 计划和临时产物默认写入 `.ai-workspace/`。
- 代码与文档冲突时，以源码、`apps/server/prisma/schema.prisma` 和 Prisma migrations 为准，并及时更新文档。
