# Linsor AI Web

Linsor AI 的 Web 客户端，基于 Vue 3、TypeScript 和 Vite 构建，为用户提供知识库管理、成员协作、文档上传和智能问答界面。

前端支持双 Token 认证、知识库角色权限展示、文件分片上传与断点续传，以及基于 AG-UI 的 Agent 执行过程展示。AI 回复通过 Incremark 增量解析 Markdown，并使用 Shiki 提供代码高亮，整体界面遵循 Kinetic Blueprint 设计规范。

主要技术包括 Vue 3、Vite、Pinia、Vue Router、Tailwind CSS、Incremark、Shiki 和 VueUse。
